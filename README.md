# Príncipe Dorminhoco


## Sobre o jogo
O jogo se baseia em RPG's de mistério e terror, onde você tem que investigar um local e resolver quebra-cabeças para prosseguir, se tratando de uma versão simplificada do gênero. No jogo você é um príncipe que acorda em seu quarto, mas tem algo diferente do habitual, você deve controlá-lo e investigar o que está acontecendo. O jogo é inspirado em outros jogos similares como undertale, omori, ib, yume nikki, yuupie psycho, entre outros rpgs similares.

## Sobre o projeto
Projeto desenvolvido para a disciplina de Computação Gráfica, consistindo em um jogo 2D implementado utilizando algoritmos  de rasterização e transformações geométricas, construído sem o uso de bibliotecas gráficas de alto nível utilizando apenas operações básicas de:
- desenho em pixel;
- incluindo rasterização de linhas;
- circunferências e elipses;
- preenchimento de regiões;
- clipping;
- transformações 2D;
- mapeamento de textura e animações interativas.

## Execução

### Pré requisitos
- Python 3.X
- pygame 

### Instalação
```bash
pip install pygame
```

### Execução
```bash
python main.py
```

## Controles

Movimentação do príncipe: Setas do teclado (também podem ser utilizados WASD)

Botão de interação: E

Inventário: R (Para selecionar os itens no inventário utilize W/S ou as setas)
