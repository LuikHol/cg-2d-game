## Sobre o jogo
O jogo se baseia em RPG's de mistério e terror, onde você tem que investigar um local e resolver quebra-cabeças para prosseguir, se tratando de uma versão simplificada do gênero. No jogo você é uma criança que pode ser identificada como o príncipe que acorda em seu quarto, mas tem algo diferente do habitual, você deve controlar o principe e investigar o que está acontecendo. O jogo é inspirado em outros jogos similares como undertale, omori, ib, yume nikki,yuupie psycho, entre outros rpgs similares.

## Sobre o projeto
Projeto desenvolvido para a disciplina de Computação Gráfica, consistindo em um jogo 2D implementado utilizando algoritmos  de rasterização e transformações geométricas, construído sem o uso de bibliotecas gráficas de alto nível utilizando apenas operações básicas de:
- desenho em pixel;
- incluindo rasterização de linhas;
- circunferências e elipses;
- preenchimento de regiões;
- clipping;
- transformações 2D;
- mapeamento de textura e animações interativas.
